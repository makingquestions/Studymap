¿Cómo funciona la aplicación de estilos en cascada?

/* Regla 1: todos los párrafos azules */
p { color: blue; }

/* Regla 2: párrafos con clase "destacado" rojos */
.destacado { color: red; }

/* Regla 3: el párrafo con id "principal" verde */
#principal { color: green; }
  • IDs tienen más prioridad que clases
  • Clases tienen más prioridad que elementos
  • Estilos en línea tienen más prioridad que todo
  • Si hay empate, la regla que aparece más abajo en el código gana.

Estilos de CSS

1. Estilo en línea: <p style="color: blue; font-size: 18px;">

2. Estilo interno: Bloque <style> dentro de <head>

3. Estilos externos: Archivo separado styles.css vinculados mediante <link>

Etiqueta <link>

Se usa para conectar el CSS externo desde el <head> de html:

<link rel="stylesheet" href="styles.css">
  • <link>: Etiqueta auto-cerrante que vincula recursos ext
  • rel="stylesheet": Especifica que es una hoja de estilo
  • href="styles.css": Ruta al archivo CSS (misma carpeta, subcarpeta o URL)

CSS básica

selector {
    propiedad: valor;
    otra-propiedad: otro-valor;
}

CSS por elementos

Afecta a etiquetas directas: p { color: blue; }, h1 { font-size: 32px; }, a { text-decoration: none; }

CSS por clases

.destacado { background-color: yellow; }

.importante { color: red; }

CSS por ID

#header { background-color: navy; color: white; padding: 20px; }

Por estados de enlace

  • a:link - Enlace no visitado
  • a:visited - Enlace visitado
  • a:hover - Enlace con el mouse encima
  • a:active - Enlace mientras se hace click
Pasa el mouse sobre este enlace (:hover)

Buenas prácticas

  • Prefiere clases sobre IDs para estilos
  • Mantén selectores simples (2-3 niveles máximo)
  • Evita selectores excesivamente específicos (#header nav ul li a)
  • Usa nombres de clases descriptivos (.btn-primary no .blue-button)
  • Agrupa selectores relacionados
  • Evita !important
  • Usa comentarios para secciones de tu CSS

Box model

Compuesto por: MARGEN (margin: 30px), BORDE (border: 3px), PADDING (padding: 20px) y CONTENIDO.

Box Sizing

1. CON box-sizing: content-box (Por defecto)
Padding y Border se suman por fuera.
Ancho total = 300px + 20px(izq) + 20px(der) + 5px(borde) + 5px(borde) = 350px
2. CON box-sizing: border-box (Recomendado)
El ancho fijado es el tamaño final exacto.
Ancho total = 300px (El contenido interno se ajusta).

Display Line/Block

DISPLAY: BLOCK (div)
Salto de línea automático. Toma todo el ancho disponible (width: 100%). Control total de W/H y márgenes.
DISPLAY: INLINE (span) Fluye como texto. Ignores Width y Height.
DISPLAY: INLINE-BLOCK
Fluye horizontalmente como inline pero respeta el control de W/H y márgenes como block.

Overflow

OVERFLOW: HIDDEN
Recorta el contenido. Útil para recortar imágenes redondeadas o evitar desbordes.
OVERFLOW: SCROLL
Barras fijas visibles siempre. Para paneles con diseño estricto o galerías fijas.
OVERFLOW: AUTO
Barra dinámica (solo si es necesario). Para modales, chats y tablas responsivas.
